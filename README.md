# Grogu Game

Este es un proyecto de juego interactivo basado en Grogu, desarrollado como parte del Módulo 3 del curso en Adalab. 
Este juego interactivo está desarrollado para aplicar y reforzar los conocimientos adquiridos en React JS. Los jugadores interactúan con un personaje inspirado en Grogu, el famoso personaje de "The Mandalorian". El objetivo es descargar toda la mercancia en la nave antes de que Grogu se coma todo. 

Puedes probar el proyecto a través de este enlace: https://lorenastn.github.io/promo-Y-module-3-pair-2-grogu-game/

## Instalación 

Si deseas instalar este proyecto de manera local:

1. Clona el repositorio

```
git clone https://github.com/LorenaSTN/promo-Y-module-3-pair-2-grogu-game.git
```

2. Instala las dependencias
   
```
npm install
```

3. Para iniciar el proyecto

```
npm run dev
```
